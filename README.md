## 本分支的“食用指南”
### 对研究复现的定位
在阅读经典文章的基础上，提炼研究者的研究逻辑，如，如何从过往的研究、经典理论和经验现实中提炼概念或聚焦具体的研究问题，如何在已有的数据的基础上对概念进行操作化，从而能够将研究假设付诸现实的检验。
### 将涉及的文件
因为主要是做定量研究，所以会涉及以下内容：
1、概念操作化的指标与对应数据库指标的映射表（.excel）
2、数据清洗、研究复现过程的do-file（.do）
3、跑完所有描述性统计、回归模型等操作的处理后的数据库（.dta 原始数据请访问CFPS官网，do文件里面会写清楚使用的数据年份）
4、梳理总体逻辑和过程的研究复现报告（.docx）
### 如何查阅这些文件
1、文件命名规则为“作者（年份）研究复现_文件内容”
2、前半部分不必多言，“_文件内容”会标注清楚是映射表/数据清洗/数据库/复现报告等
